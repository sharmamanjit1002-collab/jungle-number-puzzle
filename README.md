# 🎮 Jungle Number Puzzle

An interactive mathematical puzzle game with a fun jungle theme! Test your brain and strengthen your math skills while enjoying a beautifully designed jungle adventure.

## 🌟 Features

- **100 Levels** - Progressive difficulty from Easy to Expert
- **1,000 Unique Puzzles** - 10 questions per level
- **7 Question Types**:
  - Addition
  - Subtraction
  - Multiplication
  - Division
  - Addition Sequences
  - Subtraction Sequences
  - Square Number Sequences
  - Missing Number Problems

- **Engaging Jungle Theme** - Beautiful animated jungle background with waterfalls, mountains, and wildlife
- **Lives System** - Start with 3 lives, lose one for incorrect answers or timeouts
- **Timed Challenges** - 20 seconds per question
- **Scoring System** - Earn 10 points per correct answer
- **Sound Effects** - Background jungle music and animal sound effects
- **Fully Responsive** - Works on desktop, tablet, and mobile devices

## 🚀 Getting Started

1. Open `index.html` in a modern web browser
2. Add audio files to the `sounds/` directory (optional - game works without sound)
3. Start playing!

## 🎮 How to Play

1. **Read the Question** - Look at the mathematical puzzle
2. **Select an Answer** - Click one of the four options (A, B, C, D)
3. **Submit Your Answer** - Click "🐘 SUBMIT ANSWER"
4. **Move Forward** - Click "🐯 NEXT QUESTION"
5. **Complete All 100 Levels** - Become a Jungle Master!

## 🎯 Game Settings

- **Levels**: 100 total levels
- **Questions per Level**: 10 questions
- **Time per Question**: 20 seconds
- **Starting Lives**: 3 lives
- **Points per Correct Answer**: 10 points

## 🎨 Difficulty Progression

- **Levels 1-10** (Easy): Addition, Subtraction, Sequences
- **Levels 11-25** (Medium): Add Multiplication & Division
- **Levels 26-50** (Hard): Add Square Sequences & Missing Numbers
- **Levels 51-100** (Expert): Random mix of all types
